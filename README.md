# NLP Sentiment Classifier

A multi-class sentiment analysis project using Python, Natural Language Processing (NLP), and machine learning techniques to classify text into three sentiment categories: Negative, Neutral, and Positive.

## Project Overview

This project focuses on building an intelligent sentiment classification system using the TweetEval Sentiment dataset.

The system processes text data, extracts meaningful features, trains multiple machine learning models, and evaluates their performance.

## Objectives

- Perform text preprocessing and cleaning.
- Convert text into numerical features using TF-IDF.
- Train and compare multiple machine learning models.
- Evaluate model performance using accuracy and confusion matrices.
- Predict the sentiment of custom text inputs.

## Technologies Used

- Python
- Google Colab
- Natural Language Processing (NLP)
- TF-IDF Vectorization
- Scikit-learn
- NLTK
- Pandas
- NumPy
- Matplotlib and Seaborn

## Machine Learning Models

The following models were implemented and compared:

1. Logistic Regression
2. Linear Support Vector Classification (LinearSVC)
3. Multinomial Naive Bayes

## Results

The improved Logistic Regression model achieved the highest accuracy of 59.52%.

Other models were also evaluated to compare their performance and understand the impact of text preprocessing and feature extraction.

## Key Features

- Text cleaning and preprocessing
- Stopword removal and lemmatization
- TF-IDF feature extraction
- Multi-class sentiment classification
- Model comparison and evaluation
- Confusion matrix visualization
- Custom text sentiment prediction

## Sentiment Categories

- 0: Negative
- 1: Neutral
- 2: Positive
